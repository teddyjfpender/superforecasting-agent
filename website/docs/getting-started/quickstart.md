# Quickstart

Follow the [beta tester guide](./tester-pilot.md) to install the assigned wheels,
select an isolated profile, configure a provider and open the terminal desk.
The guide includes a synthetic forecast and the recovery and reporting steps.

Inside the desk, use `/help`; outside it, use
`superforecasting-agent forecast --help`. See [beta support scope](./beta-scope.md)
before choosing a platform or optional integration.
