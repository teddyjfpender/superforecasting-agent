# Messaging and Docs rendering review

These are real Ink frames rendered with the Terminal Amber palette and a
controlled gateway at 120×40. Names and content are synthetic. This is component
rendering evidence, not a claim of live Signal or Overleaf account verification.

- [Docs](docs.svg): library, list, Markdown reader, tables, tasks, code and wiki links.
- [Messaging](messaging.svg): collections, stable chat selection and bounded thread.

The same surfaces were inspected at 80×24, where the collection rail collapses
into keyboard navigation. Quick compose was also checked over the Docs surface.

See the [architecture and review guide](../../architecture/messaging-docs-desk.md)
for input ownership, persistent state, safeguards and integration limits.
